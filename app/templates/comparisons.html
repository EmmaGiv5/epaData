How to interpret this comparison

  • Each run uses one dataset and one measurement; values from different units are not mixed.
  • Missing or nonnumeric measurements are excluded from summaries and counted as missing.
  • Standard deviation is the sample standard deviation; it is undefined for a group with fewer than two values.
  • Percentage difference is relative to the selected reference group; it is undefined when that group's comparison value is zero.
  • Intensity and heat-rate values are missing when gross load is missing or zero.
  • Control status is classified from the available annual unit control field; unspecified entries remain a separate group.
  • These are descriptive comparisons, not statistical significance tests or causal conclusions.
