epaData

EPA Data Management, Evaluation, and Visualization System

A database-driven web application for managing, searching, analyzing, and visualizing environmental and power-sector data.

Project Overview

epaData is designed to collect, store, manage, search, evaluate, and visualize environmental and power-sector data obtained from the U.S. Environmental Protection Agency.

The system uses Flask for the web application and SQLite for the database.
